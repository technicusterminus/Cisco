# CCNA 200-301 v1.1: Anki-Deck (Deutsch)

`CCNA_200-301_v1.1_Kompendium_1.0_DE.apkg` enthält **533 Karten** zu allen 53 Prüfungszielen, verteilt auf sechs Unterdecks (eines je Domäne).

- Aufbau wie beim ENCOR-Deck: Felder ID, Ziel, Thema, Typ, Frage, Antwort, Hinweis, Quellen.
- Typen: Wissen, Szenario, CLI, Interpretation, Vergleich, Exhibit, Rechnen (Subnetting, IPv6-Kürzen, EUI-64, Wildcard).
- Tags: `CCNA_200_301`, `Ziel::2.5`, `Domaene::2`, `Typ::…`, `Stufe::…`, `Kompendium::1_0`.
- IDs der Form `C11-<Ziel>-<nnn>` und feste GUIDs: ein erneuter Import einer späteren Version aktualisiert die Karten, statt Duplikate anzulegen.
- Import: Anki → Datei → Importieren → die `.apkg` wählen.

Hinweis zur Qualität: Die Karten sind aus eigenem Fachwissen geschrieben und nicht Karte für Karte gegen die Cisco-Dokumentation geprüft. Im Zweifel gilt die Cisco-Doku. Die Quellenlinks zeigen auf die Prüfungsthemen und passende RFCs bzw. Konfigurationsleitfäden.
