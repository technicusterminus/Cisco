# 1.1.a | Befehle: Switch-Administration, MTU und Errdisable
S: https://www.cisco.com/c/en/us/support/switches/catalyst-9300-series-switches/products-command-reference-list.html | Cisco Catalyst 9300: Command References

Q: Wie stellst du auf einem Catalyst 9000 die MTU aller Ports auf Jumbo Frames?
A:
```
system mtu <bytes>
```
**Modus:** global. Beispiel `system mtu 9198`. Gilt für alle Layer-2-Ports, Layer-3-Interfaces haben zusätzlich `ip mtu`.
T: Befehl Mittel

Q: Wie holst du Ports aus allen err-disabled-Gründen automatisch zurück?
A:
```
errdisable recovery cause all
errdisable recovery interval <sekunden>
```
**Modus:** global. Welche Gründe aktiv sind und wann der nächste Versuch kommt: `show errdisable recovery`.
T: Befehl Mittel

Q: Welcher Befehl zeigt alle Ports im Zustand err-disabled mit Grund?
A:
```
show interfaces status err-disabled
```
**Modus:** privilegiert. Die Spalte „Reason“ nennt z. B. bpduguard, psecure-violation oder link-flap.
T: Befehl Leicht

Q: Wie trägst du eine MAC-Adresse statisch ein, und wie verwirfst du Frames an eine MAC?
A:
```
mac address-table static <mac> vlan <vlan-id> interface <interface>
mac address-table static <mac> vlan <vlan-id> drop
```
**Modus:** global. `drop` verwirft alle Frames mit dieser Ziel-MAC im VLAN.
T: Befehl Mittel

Q: Wie schaltest du das MAC-Lernen in einem VLAN ab?
A:
```
no mac address-table learning vlan <vlan-id>
```
**Modus:** global. Der Switch flutet dann allen Unicast im VLAN. Nur in Sonderfällen sinnvoll.
T: Befehl Schwer

# 1.1.b | Befehle: CDP und LLDP
S: https://www.cisco.com/c/en/us/support/switches/catalyst-9300-series-switches/products-command-reference-list.html | Cisco Catalyst 9300: Command References

Q: Wie aktivierst du LLDP global und schaltest es auf einem Port nur in eine Richtung?
A:
```
lldp run
interface <interface>
 no lldp transmit
 lldp receive
```
**Modus:** global bzw. Interface. Der Port lernt dann Nachbarn, verrät aber nichts über sich.
T: Befehl Mittel

Q: Welche Befehle zeigen CDP- und LLDP-Nachbarn mit Adressen und Fähigkeiten?
A:
```
show cdp neighbors detail
show lldp neighbors detail
```
**Modus:** privilegiert. `detail` liefert Management-Adresse, Version und bei CDP natives VLAN und Duplex.
T: Befehl Leicht

Q: Wie änderst du die LLDP-Sendeintervall und die Haltezeit?
A:
```
lldp timer <sekunden>
lldp holdtime <sekunden>
```
**Modus:** global. Standard: 30 Sekunden senden, 120 Sekunden halten.
T: Befehl Mittel

# 1.1.c | Befehle: VLANs, Trunks, Q-in-Q, Voice VLAN und Private VLANs
S: https://www.cisco.com/c/en/us/support/switches/catalyst-9300-series-switches/products-command-reference-list.html | Cisco Catalyst 9300: Command References

Q: Wie konfigurierst du einen Kundenport für Q-in-Q (802.1ad-Tunnel)?
A:
```
interface <kundenport>
 switchport access vlan <provider-vlan>
 switchport mode dot1q-tunnel
```
**Modus:** Interface. Der Switch setzt ein äußeres Tag mit dem Provider-VLAN auf die schon getaggten Kunden-Frames.
T: Befehl Schwer

Q: Wie tunnelst du CDP, STP und VTP des Kunden durch einen Q-in-Q-Port?
A:
```
l2protocol-tunnel cdp
l2protocol-tunnel stp
l2protocol-tunnel vtp
```
**Modus:** Interface (dot1q-tunnel). Sonst verbraucht der Provider-Switch die Kunden-BPDUs selbst.
T: Befehl Schwer

Q: Wie taggst du das native VLAN auf allen Trunks?
A:
```
vlan dot1q tag native
```
**Modus:** global. Bei Q-in-Q nötig, sonst verliert das Provider-Netz das äußere Tag beim nativen VLAN.
T: Befehl Schwer

Q: Wie legst du für Private VLANs das Primary-VLAN mit einem Isolated- und einem Community-VLAN an?
A:
```
vlan <isolated>
 private-vlan isolated
vlan <community>
 private-vlan community
vlan <primary>
 private-vlan primary
 private-vlan association <isolated>,<community>
```
**Modus:** VLAN-Modus. Bei VTPv1/v2 muss der Switch transparent sein, VTPv3 kann Private VLANs verteilen.
T: Befehl Schwer

Q: Wie machst du einen Port zum Host-Port in einem Secondary-VLAN?
A:
```
switchport mode private-vlan host
switchport private-vlan host-association <primary> <secondary>
```
**Modus:** Interface. Isolated-Hosts erreichen nur den Promiscuous-Port, Community-Hosts auch einander.
T: Befehl Schwer

Q: Wie machst du einen Port zum Promiscuous-Port für ein Private VLAN?
A:
```
switchport mode private-vlan promiscuous
switchport private-vlan mapping <primary> <secondary-liste>
```
**Modus:** Interface. Typisch der Port zum Router oder zur Firewall.
T: Befehl Schwer

Q: Wie routet eine SVI für ein Private VLAN auch die Secondary-VLANs?
A:
```
interface vlan <primary>
 private-vlan mapping <secondary-liste>
```
**Modus:** Interface (SVI). Ohne Mapping erreichen die Hosts in den Secondary-VLANs ihr Gateway nicht.
T: Befehl Schwer

Q: Welcher Befehl zeigt die Private-VLAN-Zuordnungen?
A:
```
show vlan private-vlan [type]
```
**Modus:** privilegiert. Ohne `type` erscheinen Primary, Secondary und zugeordnete Ports.
T: Befehl Mittel

Q: Wie konfigurierst du VTPv3 und machst den Switch zum Primary Server?
A:
```
vtp version 3
vtp mode server
vtp primary
```
**Modus:** global, `vtp primary` privilegiert. Nur der Primary Server darf die VLAN-Datenbank ändern.
T: Befehl Schwer

# 1.1.d | Befehle: EtherChannel
S: https://www.cisco.com/c/en/us/support/switches/catalyst-9300-series-switches/products-command-reference-list.html | Cisco Catalyst 9300: Command References

Q: Wie baust du ein LACP-Bündel mit schnellen LACPDUs und mindestens zwei aktiven Links?
A:
```
interface range <ports>
 channel-group <nr> mode active

interface port-channel <nr>

```
**Modus:** Interface. `lacp rate fast` sendet jede Sekunde, Ausfälle fallen nach 3 Sekunden auf.

Q: Wie begrenzt du einen Port-Channel auf eine Zahl aktiver Links und hältst den Rest als Hot Standby?
A:
```
lacp max-bundle <anzahl>
```
**Modus:** Port-Channel-Interface. Welche Ports aktiv werden, steuern `lacp system-priority` und `lacp port-priority`.
T: Befehl Schwer

Q: Wie erkennt STP falsch konfigurierte EtherChannels und sperrt sie?
A:
```
spanning-tree etherchannel guard misconfig
```
**Modus:** global. Bildet nur eine Seite ein Bündel, geht der Port-Channel in err-disabled statt eine Schleife zu bauen.
T: Befehl Schwer

Q: Welche Befehle zeigen EtherChannel-Status, LACP-Partner und Hashing?
A:
```
show etherchannel summary
show lacp neighbor
show etherchannel load-balance
```
**Modus:** privilegiert. „H“ in der Summary markiert Hot-Standby-Ports.
T: Befehl Mittel

# 1.1.e | Befehle: Spanning Tree, MST und Schutzfunktionen
S: https://www.cisco.com/c/en/us/support/switches/catalyst-9300-series-switches/products-command-reference-list.html | Cisco Catalyst 9300: Command References

Q: Wie richtest du eine MST-Region mit zwei Instanzen ein?
A:
```
spanning-tree mode mst
spanning-tree mst configuration
 name <region>
 revision <nr>
 instance 1 vlan <liste>
 instance 2 vlan <liste>
```
**Modus:** global. Nicht zugeordnete VLANs bleiben in Instanz 0 (IST).
T: Befehl Mittel

Q: Wie verteilst du die Root-Rollen der MST-Instanzen auf zwei Distribution-Switches?
A:
```
spanning-tree mst 1 root primary
spanning-tree mst 2 root secondary
```
**Modus:** global, auf dem zweiten Switch umgekehrt. So nutzen beide Uplinks Verkehr.
T: Befehl Mittel

Q: Wie stellst du die STP-Kostenberechnung auf 32-Bit-Werte um?
A:
```
spanning-tree pathcost method long
```
**Modus:** global. MST nutzt immer lange Kosten, bei PVST+ ist es eine Option.
T: Befehl Schwer

Q: Wie schaltest du Loop Guard global ein?
A:
```
spanning-tree loopguard default
```
**Modus:** global. Gilt für Punkt-zu-Punkt-Links. Bleiben BPDUs aus, geht der Port in loop-inconsistent statt in Forwarding.
T: Befehl Mittel

Q: Wie aktivierst du Bridge Assurance auf einem Trunk zwischen zwei Switches?
A:
```
spanning-tree portfast network
```
**Modus:** Interface. Beide Seiten senden auf jedem Port BPDUs. Bleiben sie aus, geht der Port in den Zustand BA-inconsistent.
T: Befehl Schwer

Q: Welcher Befehl zeigt, wie oft und von welchem Port zuletzt eine Topologieänderung kam?
A:
```
show spanning-tree detail | include ieee|occurr|from|is exec
```
**Modus:** privilegiert. Der Filter zeigt pro Instanz Anzahl, Zeitpunkt und Quell-Port der letzten TCN.
T: Befehl Schwer

Q: Welcher Befehl zeigt die MST-Konfiguration und die Rollen pro Instanz?
A:
```
show spanning-tree mst configuration
show spanning-tree mst <instanz> detail
```
**Modus:** privilegiert. Weicht der Digest ab, gehören Switches zu verschiedenen Regionen.
T: Befehl Mittel

# 1.2.h | Befehle: Redistribution

```

```
**Modus:** Router (OSPF). Ohne Route-Map kämen auch Loopbacks und Transfernetze dazu.
T: Befehl Mittel

Q: Wie redistribuierst du iBGP-Routen in ein IGP?
A:
```
router bgp <as>
 bgp redistribute-internal
```
**Modus:** Router. Standardmäßig redistribuiert IOS nur eBGP-Routen in IGPs, weil iBGP-Routen sonst schnell Schleifen bauen.
T: Befehl Schwer
