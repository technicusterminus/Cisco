# Netzwerk-Einstieg: Von null zum ersten eigenen Netz

Material für alle, die noch **nichts** über Netzwerke wissen, auf Deutsch, ohne Vorkenntnisse und ohne teure Hardware. Am Ende kannst du ein kleines Netz erklären, adressieren, aufbauen und Fehler eingrenzen, und bist bereit für die [CCNA](../CCNA%20200-301%20Vorbereitung/).

## Der Lernpfad

```
Kapitel lesen → Anki-Karten → Übung machen → Quiz → nächstes Kapitel
```

1. Lies ein Kapitel (10 bis 20 Minuten) und beantworte den Selbsttest.
2. Lerne die passenden Anki-Karten.
3. Mach die zugehörige Übung.
4. Teste dich im Quiz.

Der genaue Ablauf steht im [Lernplan](Lernplan.md).

## Was du brauchst

- Einen Rechner mit Windows, macOS oder Linux.
- Die kostenlosen Programme [Wireshark](https://www.wireshark.org/) und Cisco Packet Tracer (Cisco Networking Academy) für die letzten beiden Übungen.
- Keine Router, keine Switches, kein Vorwissen.
