# Anki-Deck: Netzwerk-Einstieg

`Netzwerk-Einstieg_Kompendium_1.0_DE.apkg` enthält **102 Karten** zu den 12 Kapiteln des Einsteigerpakets, auf Deutsch.

- Typen: Wissen, Vergleich, Szenario, Rechnen (Subnetting), Interpretation, CLI.
- Tags: `Netzwerk_Einstieg`, `Kapitel::01` bis `Kapitel::12`, `Typ::…`, `Stufe::…`.
- Feste IDs der Form `EIN-<Kapitel>-<nnn>`: Ein erneuter Import einer späteren Version aktualisiert die Karten.
- Import: Anki → Datei → Importieren → `.apkg` wählen.

Tipp: Lies zuerst das Kapitel, dann lerne die Karten mit dem Filter `tag:Kapitel::05` (Kapitelnummer anpassen).

Die Karten sind aus eigenem Fachwissen geschrieben. Im Zweifel gilt die Dokumentation des jeweiligen Herstellers bzw. der RFC.
