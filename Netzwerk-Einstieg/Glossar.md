# Glossar

Begriffe in Alltagssprache, alphabetisch.

| Begriff | Erklärung |
|---|---|
| **ACL** | Access Control List: Liste von Erlauben/Verbieten-Regeln für Verkehr |
| **ARP** | Findet zu einer IP-Adresse die passende MAC-Adresse im lokalen Netz |
| **Access Point (AP)** | Gerät, das WLAN-Geräte mit dem Kabelnetz verbindet |
| **Bandbreite** | Wie viele Daten pro Sekunde maximal übertragen werden können |
| **Broadcast** | Nachricht an alle Geräte im Netz |
| **Client** | Gerät oder Programm, das einen Dienst nutzt |
| **DHCP** | Verteilt IP-Adressen und weitere Einstellungen automatisch |
| **DNS** | Übersetzt Namen (`example.com`) in IP-Adressen |
| **Default Gateway** | Router, an den ein Host Pakete für fremde Netze schickt |
| **Ethernet** | Standard für kabelgebundene LANs |
| **Firewall** | Filtert Verkehr nach Regeln |
| **Frame** | Dateneinheit auf Layer 2 |
| **Hop** | Ein Router auf dem Weg zum Ziel |
| **Host** | Jedes Gerät mit IP-Adresse |
| **ICMP** | Protokoll für Diagnose und Fehlermeldungen (z. B. Ping) |
| **IP-Adresse** | Logische Adresse eines Geräts im Netz |
| **LAN / WAN** | Lokales Netz / Weitverkehrsnetz |
| **Latenz** | Verzögerung einer Übertragung |
| **MAC-Adresse** | Hardware-Adresse einer Netzwerkkarte (48 Bit) |
| **NAT / PAT** | Übersetzt private in öffentliche Adressen (PAT über Ports) |
| **Netzmaske** | Trennt Netzanteil und Hostanteil einer IP-Adresse |
| **Paket** | Dateneinheit auf Layer 3 |
| **Ping** | Testet die Erreichbarkeit eines Ziels |
| **PoE** | Stromversorgung über das Netzwerkkabel |
| **Port** | Nummer, die ein Programm auf einem Host adressiert (TCP/UDP) |
| **Protokoll** | Regelwerk, das Kommunikation festlegt |
| **Router** | Verbindet Netze und wählt Wege |
| **Routing-Tabelle** | Liste von Zielnetzen und dem Weg dorthin |
| **Server** | Stellt Dienste bereit |
| **SSID** | Name eines WLANs |
| **Subnetz** | Ein Teilnetz, durch die Maske abgegrenzt |
| **Switch** | Leitet Frames gezielt anhand von MAC-Adressen weiter |
| **TCP** | Zuverlässiges, verbindungsorientiertes Transportprotokoll |
| **TTL** | Zähler im IP-Header, begrenzt die Lebensdauer eines Pakets |
| **UDP** | Schnelles, verbindungsloses Transportprotokoll |
| **VLAN** | Logische Aufteilung eines Switches in getrennte Netze |
| **VPN** | Verschlüsselter Tunnel durch ein unsicheres Netz |
