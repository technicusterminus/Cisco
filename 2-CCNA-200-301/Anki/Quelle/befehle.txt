# 1.4 | Befehle: Interfaces, Speed, Duplex und Fehlerzähler
S: https://www.cisco.com/c/en/us/support/switches/catalyst-9300-series-switches/products-command-reference-list.html | Cisco Catalyst 9300: Command References

Q: Welcher Befehl zeigt alle Switch-Ports mit Link-Status, VLAN, Duplex und Speed in einer Zeile pro Port?
A:
```
show interfaces status
```
**Modus:** privilegiert. „a-full“ und „a-1000“ heißen: per Autonegotiation ausgehandelt.
T: Befehl Leicht

Q: Welcher Befehl zeigt Eingangsfehler, CRC-Fehler, Kollisionen und Late Collisions eines Interfaces?
A:
```
show interfaces <interface>
```
**Modus:** privilegiert. Late Collisions deuten auf einen Duplex-Mismatch hin, steigende CRC-Fehler auf Kabel oder Stecker.
T: Befehl Leicht

Q: Welcher Befehl zeigt die Fehlerzähler aller Switch-Ports in einer Tabelle?
A:
```
show interfaces counters errors
```
**Modus:** privilegiert. Spalten wie FCS-Err und Align-Err zeigen auf einen Blick, welcher Port Probleme hat.
T: Befehl Mittel

Q: Wie legst du Geschwindigkeit und Duplex eines Ports fest, statt sie auszuhandeln?
A:
```
interface <interface>
 speed {10 | 100 | 1000 | auto}
 duplex {half | full | auto}
```
**Modus:** Interface. Falle: Stellst du nur eine Seite fest ein, fällt die andere bei 10/100 Mbit/s auf Half Duplex zurück.
T: Befehl Mittel

Q: Mit welchem Befehl konfigurierst du mehrere Switch-Ports gleichzeitig?
A:
```
interface range <typ> <von> - <bis>
```
**Modus:** global. Beispiel: `interface range gi1/0/1 - 24`. Alles danach gilt für alle Ports im Bereich.
T: Befehl Leicht

Q: Mit welchem Befehl setzt du ein Interface auf seine Werkseinstellung zurück?
A:
```
default interface <interface>
```
**Modus:** global. Löscht die gesamte Interface-Konfiguration auf einmal, statt jede Zeile mit `no` zu entfernen.
T: Befehl Mittel

Q: Welcher Befehl zeigt alle Interfaces mit Status und Beschreibung, aber ohne IP-Adressen?
A:
```
show interfaces description
```
**Modus:** privilegiert. Gut, um schnell zu sehen, welche Gegenstelle an welchem Port hängt.
T: Befehl Leicht

Q: Welcher Befehl zeigt alle Interfaces mit IPv4-Adresse und Status (Line und Protocol)?
A:
```
show ip interface brief
```
**Modus:** privilegiert. „administratively down“ heißt: `shutdown` ist konfiguriert.
T: Befehl Leicht

# 1.6 | Befehle: IPv4-Adressen am Router
S: https://www.cisco.com/c/en/us/support/ios-nx-os-software/ios-xe-17/products-command-reference-list.html | Cisco IOS XE 17: Command References

Q: Wie gibst du einem Router-Interface eine IPv4-Adresse und aktivierst es?
A:
```
interface <interface>
 ip address <ip-adresse> <subnetzmaske>
 no shutdown
```
**Modus:** Interface. Router-Interfaces sind ab Werk `shutdown`, Switch-Ports nicht.
T: Befehl Leicht

Q: Wie gibst du einem Interface eine zweite IPv4-Adresse aus einem anderen Subnetz?
A:
```
ip address <ip-adresse> <subnetzmaske> secondary
```
**Modus:** Interface. Ohne `secondary` ersetzt die neue Adresse die bisherige.
T: Befehl Mittel

Q: Wie konfigurierst du ein Router-Interface so, dass es seine IPv4-Adresse per DHCP bezieht?
A:
```
interface <interface>
 ip address dhcp
```
**Modus:** Interface. Typisch für den Internet-Uplink eines kleinen Routers.
T: Befehl Leicht

# 1.8 | Befehle: IPv6-Adressen konfigurieren
S: https://www.cisco.com/c/en/us/support/ios-nx-os-software/ios-xe-17/products-command-reference-list.html | Cisco IOS XE 17: Command References

Q: Mit welchem Befehl schaltest du auf einem Router das Weiterleiten von IPv6-Paketen ein?
A:
```
ipv6 unicast-routing
```
**Modus:** global. Ohne diesen Befehl hat der Router zwar IPv6-Adressen, routet aber nicht und sendet keine Router Advertisements.
T: Befehl Leicht

Q: Wie gibst du einem Interface eine statische IPv6-Adresse mit Präfixlänge?
A:
```
ipv6 address <ipv6-adresse>/<präfixlänge>
```
**Modus:** Interface. Beispiel: `ipv6 address 2001:db8:1:1::1/64`. Die Link-Local-Adresse entsteht dabei automatisch.
T: Befehl Leicht

Q: Wie bildet ein Interface seine IPv6-Adresse aus einem /64-Präfix und der eigenen MAC-Adresse?
A:
```
ipv6 address <präfix>/64 eui-64
```
**Modus:** Interface. Der Router fügt FFFE in die Mitte der MAC ein und dreht das 7. Bit um.
T: Befehl Mittel

Q: Wie legst du auf einem Interface eine eigene Link-Local-Adresse fest?
A:
```
ipv6 address <fe80-adresse> link-local
```
**Modus:** Interface. Beispiel: `ipv6 address fe80::1 link-local`. Feste Link-Locals machen Next Hops und Ausgaben lesbarer.
T: Befehl Mittel

Q: Wie lässt du ein Router-Interface seine IPv6-Adresse per SLAAC selbst bilden?
A:
```
ipv6 address autoconfig
```
**Modus:** Interface. Das Interface übernimmt das Präfix aus dem Router Advertisement des Nachbarn.
T: Befehl Mittel

Q: Wie aktivierst du IPv6 auf einem Interface, ohne eine globale Adresse zu vergeben?
A:
```
ipv6 enable
```
**Modus:** Interface. Das Interface bekommt nur eine Link-Local-Adresse. Reicht z. B. für Transfernetze mit OSPFv3.
T: Befehl Mittel

Q: Welcher Befehl zeigt alle Interfaces mit ihren IPv6-Adressen und dem Status?
A:
```
show ipv6 interface brief
```
**Modus:** privilegiert. Pro Interface erscheinen Link-Local und globale Adressen untereinander.
T: Befehl Leicht

Q: Welcher Befehl zeigt die IPv6-Nachbartabelle, also das IPv6-Gegenstück zur ARP-Tabelle?
A:
```
show ipv6 neighbors
```
**Modus:** privilegiert. Die Einträge entstehen über Neighbor Discovery (NS/NA), nicht über ARP.
T: Befehl Mittel

# 1.10 | Befehle: IP-Parameter auf Windows, macOS und Linux
S: https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/ipconfig | Microsoft: ipconfig

Q: Mit welchem Befehl siehst du unter Windows IP, Maske, Gateway, DNS-Server, MAC und DHCP-Server?
A:
```
ipconfig /all
```
**Modus:** Eingabeaufforderung (Windows). Eine 169.254.x.x-Adresse heißt: kein DHCP-Server erreichbar (APIPA).
T: Befehl Leicht

Q: Mit welchem Befehl zeigt Linux die IP-Adressen aller Interfaces?
A:
```
ip addr show
```
**Modus:** Terminal (Linux). Auf macOS und älteren Linux-Systemen: `ifconfig`.
T: Befehl Leicht

Q: Mit welchem Befehl siehst du unter Linux das Default-Gateway?
A:
```
ip route show
```
**Modus:** Terminal (Linux). Die Zeile „default via …“ ist das Gateway. Unter Windows: `route print`, unter macOS: `netstat -rn`.
T: Befehl Mittel

Q: Mit welchen Befehlen fordert ein Windows-PC eine neue DHCP-Adresse an?
A:
```
ipconfig /release
ipconfig /renew
```
**Modus:** Eingabeaufforderung (Windows). Erst Adresse zurückgeben, dann neu anfragen.
T: Befehl Leicht

Q: Welcher Befehl zeigt am PC die gelernten Zuordnungen von IP zu MAC?
A:
```
arp -a
```
**Modus:** Eingabeaufforderung (Windows, macOS, Linux). Steht das Gateway nicht drin, scheitert schon die Auflösung auf Layer 2.
T: Befehl Leicht

Q: Mit welchem Befehl prüfst du am PC, welche IP-Adresse ein DNS-Name hat?
A:
```
nslookup <name>
```
**Modus:** Eingabeaufforderung oder Terminal. Unter Linux und macOS liefert `dig <name>` mehr Details.
T: Befehl Leicht

# 1.13 | Befehle: MAC-Tabelle
S: https://www.cisco.com/c/en/us/support/switches/catalyst-9300-series-switches/products-command-reference-list.html | Cisco Catalyst 9300: Command References

Q: Welcher Befehl zeigt die MAC-Adresstabelle eines Switches, optional gefiltert nach Adresse, Typ oder VLAN?
A:
```
show mac address-table [address <mac> | dynamic | vlan <vlan-id> | interface <interface>]
```
**Modus:** privilegiert. Beispiel: `show mac address-table address 0050.7966.6800` zeigt, an welchem Port ein Gerät hängt.
T: Befehl Leicht

Q: Wie trägst du eine MAC-Adresse fest für ein VLAN und einen Port in die MAC-Tabelle ein?
A:
```
mac address-table static <mac> vlan <vlan-id> interface <interface>
```
**Modus:** global. Statische Einträge altern nicht und werden nicht überschrieben.
T: Befehl Mittel

Q: Mit welchem Befehl löschst du gelernte MAC-Einträge, gezielt nach Adresse, Interface oder VLAN?
A:
```
clear mac address-table dynamic [address <mac> | interface <interface> | vlan <vlan-id>]
```
**Modus:** privilegiert. Statische Einträge bleiben stehen. Ohne Zusatz löscht der Befehl alle dynamischen Einträge.
T: Befehl Mittel

Q: Mit welchem Befehl änderst du, wie lange ein Switch eine ungenutzte MAC-Adresse in der Tabelle behält?
A:
```
mac address-table aging-time <sekunden>
```
**Modus:** global. Standard sind 300 Sekunden.
T: Befehl Mittel

# 2.1 | Befehle: VLANs und Inter-VLAN-Routing
S: https://www.cisco.com/c/en/us/support/switches/catalyst-9300-series-switches/products-command-reference-list.html | Cisco Catalyst 9300: Command References

Q: Wie legst du ein VLAN an und gibst ihm einen Namen?
A:
```
vlan <vlan-id>
 name <vlan-name>
```
**Modus:** global, dann VLAN-Modus. Das VLAN ist sofort aktiv, der Name ist nur zur Orientierung.
T: Befehl Leicht

Q: Wie machst du einen Port zum Access-Port in einem bestimmten VLAN?
A:
```
interface <interface>
 switchport mode access
 switchport access vlan <vlan-id>
```
**Modus:** Interface. `switchport mode access` schaltet DTP ab, der Port wird nie zum Trunk.
T: Befehl Leicht

Q: Wie gibst du einem Access-Port zusätzlich ein Voice-VLAN für ein IP-Telefon?
A:
```
switchport voice vlan <vlan-id>
```
**Modus:** Interface. Das Telefon taggt seinen Sprachverkehr in diesem VLAN, der PC dahinter bleibt ungetaggt im Access-VLAN.
T: Befehl Mittel

Q: Welcher Befehl zeigt alle VLANs mit Namen, Status und zugeordneten Access-Ports?
A:
```
show vlan [brief | id <vlan-id> | name <vlan-name> | summary]
```
**Modus:** privilegiert. Trunk-Ports erscheinen hier nicht.
T: Befehl Leicht

Q: Wie richtest du auf einem Router ein Subinterface für VLAN 10 ein (Router-on-a-Stick)?
A:
```
interface <interface>.<sub-id>
 encapsulation dot1Q <vlan-id>
 ip address <ip-adresse> <maske>
```
**Modus:** global, dann Subinterface. Das physische Interface braucht `no shutdown`, aber keine IP-Adresse.
T: Befehl Mittel

Q: Wie legst du auf einem Router-Subinterface fest, dass es das native VLAN ungetaggt verarbeitet?
A:
```
encapsulation dot1Q <vlan-id> native
```
**Modus:** Subinterface. Die VLAN-ID muss zum nativen VLAN des Switch-Trunks passen.
T: Befehl Schwer

Q: Wie schaltest du auf einem Layer-3-Switch das Routing ein und gibst VLAN 10 ein Gateway (SVI)?
A:
```
ip routing
interface vlan <vlan-id>
 ip address <ip-adresse> <maske>
 no shutdown
```
**Modus:** global, dann Interface. Die SVI geht nur up, wenn das VLAN existiert und mindestens ein Port darin aktiv ist.
T: Befehl Mittel

Q: Wie machst du aus einem Switch-Port einen gerouteten Port mit eigener IP-Adresse?
A:
```
interface <interface>
 no switchport
 ip address <ip-adresse> <maske>
```
**Modus:** Interface. Der Port gehört danach zu keinem VLAN mehr und verhält sich wie ein Router-Interface.
T: Befehl Mittel

# 2.2 | Befehle: Trunks und 802.1Q
S: https://www.cisco.com/c/en/us/support/switches/catalyst-9300-series-switches/products-command-reference-list.html | Cisco Catalyst 9300: Command References

Q: Wie konfigurierst du einen Port fest als 802.1Q-Trunk?
A:
```
interface <interface>
 switchport trunk encapsulation dot1q
 switchport mode trunk
```
**Modus:** Interface. Die erste Zeile brauchen nur Switches, die auch ISL können. Catalyst 9000 kennen nur 802.1Q.
T: Befehl Leicht

Q: Wie änderst du das native VLAN eines Trunks?
A:
```
switchport trunk native vlan <vlan-id>
```
**Modus:** Interface. Muss auf beiden Seiten gleich sein, sonst meldet CDP einen Native-VLAN-Mismatch.
T: Befehl Mittel

Q: Wie legst du fest, welche VLANs über einen Trunk dürfen, und wie fügst du später eines hinzu?
A:
```
switchport trunk allowed vlan <liste>
switchport trunk allowed vlan add <vlan-id>
```
**Modus:** Interface. Falle: Ohne `add` überschreibt der Befehl die ganze Liste.
T: Befehl Mittel

Q: Wie schaltest du DTP auf einem Trunk-Port ab?
A:
```
switchport nonegotiate
```
**Modus:** Interface. Der Port sendet dann keine DTP-Frames mehr. Geht nur bei `switchport mode trunk` oder `access`.
T: Befehl Mittel

Q: Wie lässt du einen Port per DTP aktiv einen Trunk aushandeln?
A:
```
switchport mode dynamic desirable
```
**Modus:** Interface. Desirable fragt aktiv an, `dynamic auto` wartet nur. Zwei Auto-Ports bilden keinen Trunk.
T: Befehl Mittel

Q: Welcher Befehl zeigt alle Trunks mit Modus, nativem VLAN und den erlaubten und aktiven VLANs?
A:
```
show interfaces trunk
```
**Modus:** privilegiert. Fehlt ein VLAN in „allowed and active“, fehlt es entweder in der Allowed-Liste oder auf dem Switch.
T: Befehl Leicht

Q: Welcher Befehl zeigt die Layer-2-Einstellungen eines einzelnen Ports, z. B. Betriebsmodus und Access-VLAN?
A:
```
show interfaces <interface> switchport
```
**Modus:** privilegiert. „Operational Mode“ zeigt, ob der Port gerade Trunk oder Access ist.
T: Befehl Mittel

# 2.4 | Befehle: EtherChannel
S: https://www.cisco.com/c/en/us/support/switches/catalyst-9300-series-switches/products-command-reference-list.html | Cisco Catalyst 9300: Command References

Q: Wie bündelst du zwei Ports per LACP zu einem EtherChannel, sodass der Switch aktiv verhandelt?
A:
```
interface range <port1> , <port2>
 channel-group <nummer> mode active
```
**Modus:** Interface. Gegenstelle `active` oder `passive`. Zwei passive Seiten bilden kein Bündel.
T: Befehl Leicht

Q: Mit welchem Modus bildest du einen EtherChannel ganz ohne Aushandlungsprotokoll?
A:
```
channel-group <nummer> mode on
```
**Modus:** Interface. Beide Seiten brauchen `on`. Ein Fehler auf einer Seite kann eine Schleife erzeugen, weil nichts prüft.
T: Befehl Mittel

Q: Wie bildest du einen EtherChannel mit dem Cisco-Protokoll PAgP?
A:
```
channel-group <nummer> mode {desirable | auto}
```
**Modus:** Interface. Desirable verhandelt aktiv, Auto wartet. Mindestens eine Seite muss desirable sein.
T: Befehl Mittel

Q: Welcher Befehl zeigt alle EtherChannels mit Protokoll und Status der Member-Ports?
A:
```
show etherchannel summary
```
**Modus:** privilegiert. „SU“ heißt Layer 2 und in Betrieb, „P“ am Port heißt gebündelt, „s“ suspendiert, „I“ eigenständig.
T: Befehl Leicht

Q: Wie stellst du ein, nach welchen Feldern ein Switch den Verkehr auf die Links eines EtherChannels verteilt?
A:
```
port-channel load-balance <methode>
```
**Modus:** global. Beispiel: `port-channel load-balance src-dst-ip`. Prüfen mit `show etherchannel load-balance`.
T: Befehl Mittel

Q: Wie baust du einen Layer-3-EtherChannel mit eigener IP-Adresse?
A:
```
interface range <ports>
 no switchport
 channel-group <nummer> mode active
interface port-channel <nummer>
 ip address <ip-adresse> <maske>
```
**Modus:** Interface. `no switchport` muss auf den Member-Ports stehen, bevor sie ins Bündel gehen.
T: Befehl Schwer

# 2.5 | Befehle: Rapid PVST+
S: https://www.cisco.com/c/en/us/support/switches/catalyst-9300-series-switches/products-command-reference-list.html | Cisco Catalyst 9300: Command References

Q: Mit welchem Befehl stellst du einen Switch auf Rapid PVST+ um?
A:
```
spanning-tree mode rapid-pvst
```
**Modus:** global. Andere Optionen: `pvst` (klassisch 802.1D pro VLAN) und `mst`.
T: Befehl Leicht

Q: Wie machst du einen Switch für ein VLAN zur Root Bridge, ohne die Priorität selbst auszurechnen?
A:
```
spanning-tree vlan <vlan-id> root primary
```
**Modus:** global. Setzt die Priorität auf 24576 oder knapp unter die der aktuellen Root. `root secondary` setzt 28672.
T: Befehl Leicht

Q: Wie setzt du die Bridge-Priorität eines Switches für ein VLAN direkt?
A:
```
spanning-tree vlan <vlan-id> priority <wert>
```
**Modus:** global. Nur Vielfache von 4096 (0 bis 61440). Kleiner gewinnt.
T: Befehl Mittel

Q: Wie änderst du die STP-Kosten eines Ports für ein bestimmtes VLAN?
A:
```
spanning-tree vlan <vlan-id> cost <kosten>
```
**Modus:** Interface. Kleinere Kosten machen den Weg über diesen Port zur Root attraktiver.
T: Befehl Mittel

Q: Wie schaltest du an einem Access-Port zum PC PortFast ein?
A:
```
spanning-tree portfast
```
**Modus:** Interface. Neuere IOS-XE-Versionen schreiben `spanning-tree portfast edge`. Der Port geht sofort in Forwarding.
T: Befehl Leicht

Q: Wie schaltest du PortFast für alle Access-Ports des Switches auf einmal ein?
A:
```
spanning-tree portfast default
```
**Modus:** global. Gilt nur für Access-Ports, nicht für Trunks. Neuere Syntax: `spanning-tree portfast edge default`.
T: Befehl Mittel

Q: Wie sorgst du dafür, dass ein PortFast-Port abschaltet, sobald dort eine BPDU ankommt?
A:
```
spanning-tree bpduguard enable
```
**Modus:** Interface. Global für alle PortFast-Ports: `spanning-tree portfast bpduguard default`. Der Port geht in err-disabled.
T: Befehl Mittel

Q: Wie verhinderst du, dass ein Switch hinter einem Port Root Bridge wird?
A:
```
spanning-tree guard root
```
**Modus:** Interface. Kommt eine bessere BPDU, geht der Port in „root-inconsistent“ statt in Forwarding.
T: Befehl Mittel

Q: Welcher Befehl zeigt für ein VLAN die Root Bridge, die eigene Priorität und Rolle und Zustand jedes Ports?
A:
```
show spanning-tree vlan <vlan-id>
```
**Modus:** privilegiert. „This bridge is the root“ steht nur auf der Root Bridge.
T: Befehl Leicht

Q: Welcher Befehl zeigt Modus und globale Schutzfunktionen von STP wie PortFast Default und BPDU Guard?
A:
```
show spanning-tree summary
```
**Modus:** privilegiert. Zeigt auch, für welche VLANs der Switch Root ist.
T: Befehl Mittel

Q: Wie holst du einen Port automatisch aus err-disabled zurück, nachdem BPDU Guard ausgelöst hat?
A:
```
errdisable recovery cause bpduguard
errdisable recovery interval <sekunden>
```
**Modus:** global. Ohne Recovery hilft nur `shutdown` und `no shutdown` am Port.
T: Befehl Schwer

Q: Wie beschränkst du SSH-Zugriff auf das Gerät mit einer ACL?
A:
```
line vty 0 15
 access-class <acl> in
```
**Modus:** Line. Auf VTY-Lines heißt der Befehl `access-class`, nicht `access-group`.
T: Befehl Mittel

Q: Wie fügst du in einer benannten ACL eine Regel zwischen Zeile 10 und 20 ein?
A:
```
ip access-list extended <name>
 15 <permit|deny> <bedingung>
```
**Modus:** ACL. Neue Nummern abstufen mit `ip access-list resequence <name> 10 10`.
T: Befehl Mittel

Q: Wie versiehst du eine ACL mit einem Kommentar?
A:
```
remark <text>
```
**Modus:** ACL. Bei nummerierten ACLs: `access-list 10 remark <text>`.
T: Befehl Leicht

Q: Welcher Befehl zeigt alle ACLs mit ihren Treffern pro Zeile?
A:
```
show access-lists [<name>]
```
**Modus:** privilegiert. Treffer zurücksetzen mit `clear access-list counters`.
T: Befehl Leicht

Q: Welcher Befehl zeigt, welche ACL auf einem Interface in welche Richtung angewendet ist?
A:
```
show ip interface <interface>
```
**Modus:** privilegiert. Gesucht sind die Zeilen „Outgoing access list“ und „Inbound access list“.
T: Befehl Mittel

# 5.7 | Befehle: Port Security, DHCP Snooping und DAI
S: https://www.cisco.com/c/en/us/support/switches/catalyst-9300-series-switches/products-command-reference-list.html | Cisco Catalyst 9300: Command References

Q: Wie schaltest du Port Security auf einem Access-Port ein und erlaubst zwei MAC-Adressen?
A:
```
interface <interface>
 switchport mode access
 switchport port-security
 switchport port-security maximum 2
```
**Modus:** Interface. Port Security geht nur auf statischen Access- oder Trunk-Ports, nicht im DTP-Modus.
T: Befehl Mittel

Q: Wie lernt Port Security die erlaubten MAC-Adressen selbst und speichert sie in der Konfiguration?
A:
```
switchport port-security mac-address sticky
```
**Modus:** Interface. Die Adressen erscheinen in der Running-Config und bleiben nach dem Speichern erhalten.
T: Befehl Mittel

Q: Wie legst du fest, was Port Security bei einer fremden MAC-Adresse tut?
A:
```
switchport port-security violation {protect | restrict | shutdown}
```
**Modus:** Interface. Shutdown (Standard) sperrt den Port, restrict verwirft und zählt, protect verwirft still.
T: Befehl Mittel

Q: Welcher Befehl zeigt die Port-Security-Einstellungen und Verstöße eines Ports?
A:
```
show port-security interface <interface>
```
**Modus:** privilegiert. „Security Violation Count“ zeigt, wie oft fremde Adressen kamen.
T: Befehl Leicht

Q: Wie schaltest du DHCP Snooping für VLAN 10 ein?
A:
```
ip dhcp snooping
ip dhcp snooping vlan 10
```
**Modus:** global. Ohne die globale Zeile wirkt die VLAN-Zeile nicht.
T: Befehl Mittel

Q: Wie markierst du den Uplink zum echten DHCP-Server bei DHCP Snooping als vertrauenswürdig?
A:
```
interface <uplink>
 ip dhcp snooping trust
```
**Modus:** Interface. Auf allen anderen Ports verwirft der Switch DHCP-Antworten (OFFER, ACK).
T: Befehl Mittel

Q: Wie begrenzt du die Zahl der DHCP-Pakete pro Sekunde an einem Access-Port?
A:
```
ip dhcp snooping limit rate <pakete-pro-sekunde>
```
**Modus:** Interface. Schützt vor DHCP-Starvation. Bei Überschreitung geht der Port in err-disabled.
T: Befehl Schwer

Q: Welcher Befehl zeigt die von DHCP Snooping gelernten Zuordnungen von IP, MAC, VLAN und Port?
A:
```
show ip dhcp snooping binding
```
**Modus:** privilegiert. Diese Tabelle nutzen DAI und IP Source Guard.
T: Befehl Mittel

Q: Wie schaltest du Dynamic ARP Inspection für VLAN 10 ein?
A:
```
ip arp inspection vlan 10
```
**Modus:** global. DAI prüft ARP-Pakete gegen die DHCP-Snooping-Tabelle.
T: Befehl Mittel

Q: Wie nimmst du einen Uplink von der ARP-Prüfung aus?
A:
```
ip arp inspection trust
```
**Modus:** Interface. Ohne Trust auf dem Uplink verwirft der Switch auch legitime ARP-Pakete von anderen Switches.
T: Befehl Mittel

Q: Welcher Befehl zeigt Einstellungen und verworfene Pakete von DAI für ein VLAN?
A:
```
show ip arp inspection vlan <vlan-id>
```
**Modus:** privilegiert. Statistik pro VLAN: `show ip arp inspection statistics`.
T: Befehl Schwer

# 5.8 | Befehle: AAA
S: https://www.cisco.com/c/en/us/support/ios-nx-os-software/ios-xe-17/products-command-reference-list.html | Cisco IOS XE 17: Command References

Q: Mit welchem Befehl schaltest du AAA auf einem Cisco-Gerät ein?
A:
```
aaa new-model
```
**Modus:** global. Ab dann gelten AAA-Methodenlisten statt der alten Line-Passwörter. Vorher einen lokalen Benutzer anlegen.
T: Befehl Leicht

Q: Wie trägst du einen RADIUS-Server mit Schlüssel ein?
A:
```
radius server <name>
 address ipv4 <server-ip>
 key <schlüssel>
```
**Modus:** global, dann RADIUS-Server. Für TACACS+ entsprechend `tacacs server <name>`.
T: Befehl Mittel

Q: Wie legst du fest, dass die Anmeldung zuerst über RADIUS läuft und bei Ausfall lokal?
A:
```
aaa authentication login default group radius local
```
**Modus:** global. `local` greift nur, wenn der Server nicht antwortet, nicht bei falschem Passwort.
T: Befehl Mittel
